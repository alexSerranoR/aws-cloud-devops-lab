# AWS Cloud DevOps Lab

Hands-on Cloud and DevOps project focused on deploying a containerized application to AWS.

## Goals

- Learn AWS fundamentals
- Containerize an application with Docker
- Deploy using Amazon ECS and Fargate
- Manage infrastructure using Terraform
- Implement CI/CD using GitHub Actions
- Add monitoring and security practices

## Tech Stack

- Python
- FastAPI
- Docker
- AWS
- Terraform
- GitHub Actions
